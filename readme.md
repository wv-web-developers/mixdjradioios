
# Mix Dj Radio — iOS (.ipa)

Sideload build of **Mix Dj Radio** for iPhone. Install with **TrollStore** or **Sideloadly**.

**Latest:** v3.0 (build 30) · bundle id `com.mixdjradio.app` · requires iOS 15+

## Download

Grab the `.ipa` from the [latest release »](../../releases/latest)

## Install

### TrollStore (permanent, no computer needed)
1. On a device with TrollStore installed, open the release above and download the `.ipa`, **or** use **TrollStore → + → Install from URL** and paste the direct `.ipa` link.
2. Tap the `.ipa` → **Install**. TrollStore signs it on-device — no Apple ID required, and it never expires.

### Sideloadly (any device)
1. Download the `.ipa` to a Mac or PC and open **Sideloadly** — <https://sideloadly.io>.
2. Connect your iPhone, drag the `.ipa` into Sideloadly, enter your **Apple ID**, then click **Start**.
3. On the iPhone: **Settings → General → VPN & Device Management** → trust your developer profile.
   - Free Apple ID: re-sign every **7 days**. Paid Apple Developer account: lasts **1 year**.
